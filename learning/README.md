# Eamon XGBoost Model Dojo

Run the local LeetCode-style lesson UI from the repository root:

```bash
python learning/eamon_xgboost_dojo.py 8787
```

Then open:

```text
http://127.0.0.1:8787
```

The app serves twelve cell-style exercises that follow Eamon's model progression:

1. Price panel and return matrix basics
2. Basic XGBoost feature/target construction
3. First tiny `XGBClassifier`
4. Toolkit prediction contract
5. Rank long-only portfolio weights
6. Minimum-variance backbone
7. Centered XGBoost tilt
8. Volatility feature pack
9. Exponentially weighted factor window
10. FF5 factor covariance
11. Rolling no-leakage rebalance lookup
12. Submission manifest

Each lesson gives prerequisites, a direct implementation problem, starter code, and hidden tests run by the local Python backend.
